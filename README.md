# 🎯 QuizApp - Plateforme de Quiz en Ligne

Application web full-stack (Monorepo) permettant de créer, jouer et gérer des quiz interactifs.

## 📁 Structure du projet
- `/frontend` : Application React (Vite, Tailwind CSS)
- `/backend` : API REST Laravel (PHP 8.2, Sanctum)

## 🚀 Fonctionnalités principales
- Modes de jeu variés (Classique, Live avec code PIN, Défier l'IA)
- Chronomètre en temps réel et calcul du score côté serveur
- Tableau de bord administrateur (CRUD des quiz, questions, réponses)
- Classement (Leaderboard) et historique de progression

## ⚙️ Stack Technique
- **Frontend :** React 19, React Router, Axios
- **Backend :** Laravel 11, MySQL 8
